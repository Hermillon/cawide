# Security Policy

## Supported Versions

Only the latest minor release of Cawide receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.13.x  | :white_check_mark: |
| < 0.13  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately:

- **Private Reporting**: Submit an advisory through [GitHub Security Advisories](https://github.com/Hermillon/cawide/security/advisories/new).
- **Public Issues**: **Never** use public GitHub issues or discussions to report security vulnerabilities.

### Response Timeline

- **Acknowledgment**: Within 5 business days of submission.
- **Coordinated Disclosure**: We aim to resolve and disclose confirmed vulnerabilities within 90 days of the report, coordinating release dates with the finder.

## Scope

This security policy covers the open-source Cawide repository. Security reports regarding the Cawide iOS mobile application or Cawide Cloud service may also be submitted through the same private security advisory channel and will be triaged privately.
